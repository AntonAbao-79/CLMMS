    • 📝About Our System

    The Computer Laboratory Maintenance Management System (CLMMS) is a simple website that helps students and instructors report computer laboratory issues.It also helps the laboratory technician organize and monitor maintenance requests, so problems can be resolved faster and more efficiently.

    ⚙️How It Works

    1

    Report

    Fill out the issue form with the details.

    2

    Track

    View the status in the reports section.

    3

    Track

    Technician fixes the issue and updates the status.

    🎯 Our Goal

    ✓ Make reporting easier and more organized.

    ✓ Track and monitor maintenance request.

    ✓ Improve the computer laboratory experience.
